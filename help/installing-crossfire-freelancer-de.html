Crossfire Freelancer auf Deutsch installieren

Diese kurze Anleitung führt dich von einer frischen Freelancer-Installation bis zum deutschen Crossfire-Start über den EXE2-Ordner.

Inhalt

  1. Frische Freelancer-Installation vorbereiten
  2. Crossfire installieren und aktualisieren
  3. Deutsche Dateien einspielen
  4. Crossfire auf Deutsch starten

1. Frische Freelancer-Installation vorbereiten

  1. Installiere Freelancer frisch und ohne andere Mods.
  2. Starte die Grundinstallation bei Bedarf einmal kurz, um sicherzugehen, dass Freelancer sauber installiert wurde.
  3. Behalte diese Installation möglichst unverändert, bis der Crossfire-Installer sie verwendet hat.

2. Crossfire-Mod installieren und updaten

  1. Lade den Crossfire-Mod herunter: Crossfire Mod Download.
  2. Installiere den Crossfire-Mod. Als Zielordner wird in dieser Anleitung C:\Freelancer Crossfire verwendet.
  3. Starte danach die Freelancer.exe direkt im Crossfire-Ordner.
  4. Führe das Update durch. Klicke dafür im Launcher einmal auf Multiplayer, damit der Crossfire-Updater seine Dateien aktualisiert.
Wichtig: Spiele das deutsche Paket erst nach diesem Update ein. So vermeidest du, dass der Updater die deutschen Dateien direkt wieder überschreibt.

3. Deutsches Sprachpaket einspielen

  1. Schließe Freelancer und den Crossfire-Launcher vollständig.
  2. Entpacke crossfire_de.7z direkt über den Ordner C:\Freelancer Crossfire.
  3. Bestätige beim Entpacken, dass vorhandene Dateien überschrieben werden dürfen.

4. Crossfire auf Deutsch starten

  1. Öffne im Crossfire-Verzeichnis den Ordner EXE2.
  2. Starte dort die Freelancer.exe.
  3. Wenn alles geklappt hat, startet Crossfire nun mit deutschen Texten.
Kurzfassung: Erst Crossfire installieren und updaten, dann crossfire_de.7z über C:\Freelancer Crossfire entpacken und anschließend EXE2\Freelancer.exe starten.
