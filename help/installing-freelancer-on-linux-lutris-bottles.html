Installing Freelancer on Linux with Lutris or Bottles

This is a simple setup guide for installing vanilla Freelancer and multiple mods on Linux. The recommended approach is to keep vanilla and every mod in its own separate Lutris prefix or Bottles bottle. That makes updates, saves, and MPID handling much easier.

Contents

  1. Install a runner
  2. Install vanilla Freelancer
  3. Install a mod
  4. Install dependencies
  5. Use FL Atlas Launcher for MPIDs

1. Install a runner

You can use either Lutris or Bottles. Lutris is a very good choice if you want to manage several Freelancer installations side by side. Bottles is a good alternative if you prefer separate self-contained bottles.

1.1 Install Lutris

  1. Install Lutris using your distribution package manager or the official Lutris installation method.
  2. Start Lutris once so it can initialize its folders and Wine runners.
  3. Create a separate game entry for each Freelancer installation you want to maintain, for example one for vanilla, one for Discovery, and one for Crossfire.
  4. Use a separate Wine prefix for each installation. This keeps registry data, saves, and dependencies isolated.

Detailed todo list for Lutris:

  1. Open the Lutris website or your distribution software manager and install Lutris.
  2. Start Lutris and wait until the first-time setup is finished.
  3. Click the plus button and create a new local game entry.
  4. Choose Wine as the runner.
  5. Enter a clear game name such as Freelancer Vanilla, Freelancer Discovery, or Freelancer Crossfire.
  6. Set the executable to the Freelancer installer first, or later to the final Freelancer EXE after installation.
  7. Open the runner options and set a dedicated Wine prefix path for this installation.
  8. Save the entry and start it once so Lutris creates the Wine prefix.
  9. Run the installation and then update the executable path to the real Freelancer game EXE if necessary.

Examples by distribution:

  • Ubuntu / Debian: update package sources, then install Lutris with sudo apt install lutris.
  • Fedora: install Lutris with sudo dnf install lutris.
  • Arch Linux: install Lutris with sudo pacman -S lutris.

1.2 Alternative: Install Bottles

  1. Install Bottles from your distribution source, Flatpak, or your preferred package source.
  2. Create one Gaming bottle for vanilla Freelancer.
  3. Create additional bottles for every major mod you want to keep separate.
  4. Name the bottles clearly so you always know which bottle belongs to which Freelancer installation.

Detailed todo list for Bottles:

  1. Install Bottles and start it once.
  2. Create a new bottle and choose the Gaming environment.
  3. Name the bottle clearly, for example Freelancer Vanilla or Freelancer Discovery.
  4. Open the bottle and use the option to run an executable.
  5. Run the Freelancer installer inside that bottle.
  6. After installation, add or select the correct Freelancer EXE as the launch target.
  7. Create one separate bottle per major mod or separate installation.

Examples by distribution:

  • Ubuntu / Debian: install Flatpak if needed, add Flathub, then install Bottles with flatpak install flathub com.usebottles.bottles.
  • Fedora: Flatpak support is usually already available, so install Bottles with flatpak install flathub com.usebottles.bottles.
  • Arch Linux: install Bottles from Flathub with flatpak install flathub com.usebottles.bottles, or use your preferred Arch package source if you already maintain it there.

2. Install vanilla Freelancer

  1. Create a fresh Lutris prefix or Bottles bottle for vanilla Freelancer.
  2. Run the original Freelancer installer inside that environment.
  3. Finish the installation and start the game once to verify that the base installation works.
  4. After the first successful start, keep this installation as your clean vanilla base.
  5. If you want, make a backup copy before applying any widescreen patch, HD pack, or mod.
Tip: do not install your first mod into the same prefix or bottle that you want to keep as a clean vanilla reference.

3. Install a mod

  1. Create a new Lutris entry with a new prefix, or create a new bottle in Bottles.
  2. Install vanilla Freelancer again inside that new environment, or copy a clean working vanilla installation into it.
  3. Install the mod into this separate environment.
  4. Launch the mod once directly from Lutris or Bottles and confirm that it starts correctly.
  5. Repeat this process for every additional mod. One mod should ideally have its own prefix or bottle.

This structure is simple and reliable:

  • one vanilla install
  • one separate install for Discovery
  • one separate install for Crossfire
  • one separate install for any other total conversion or heavily modified setup

4. Install dependencies

After vanilla or a mod is installed, add the common Windows components inside the same Lutris prefix or Bottles bottle.

  • dotnet40
  • directplay

Install these dependencies separately for each Freelancer environment where they are needed. If you use several mods in several prefixes or bottles, each one may need its own dependency setup.

Install dependencies in Lutris

  1. Open the Lutris game entry for the Freelancer installation.
  2. Open the game menu and choose the option to run Winetricks.
  3. Select the default wineprefix.
  4. Open the category for installing a Windows DLL or component.
  5. Install directplay.
  6. Repeat the same process and install dotnet40.
  7. Wait until both installs are complete, then launch the game again.

Install dependencies in Bottles

  1. Open the correct Freelancer bottle in Bottles.
  2. Go to the dependencies section of that bottle.
  3. Search for and install directplay.
  4. Search for and install dotnet40.
  5. Wait until Bottles finishes both dependency installs.
  6. Start Freelancer again from that bottle and verify that the setup still works.

5. Use FL Atlas Launcher for managing different MPIDs on Freelancer installations within Lutris and Bottles

Once your installs are working, use FL Atlas Launcher to manage them more comfortably.

  1. Add each Freelancer installation to FL Atlas Launcher.
  2. For Lutris installs, point the launcher to the correct game EXE and prefix.
  3. For Bottles installs, point the launcher to the bottle path or to the correct Wine environment for that install.
  4. Use the launcher to keep different MPIDs separate between your vanilla and modded installations.
  5. This is especially useful if you use different multiplayer identities on different Freelancer servers or mods.

Recommended structure:

  • Vanilla Freelancer → own prefix or bottle → own MPID profile if needed
  • Discovery → own prefix or bottle → own MPID profile
  • Crossfire → own prefix or bottle → own MPID profile
Keeping installs separated is the cleanest approach. It reduces registry conflicts, avoids mixed save data, and makes FL Atlas Launcher much easier to use with Lutris and Bottles.
