Enjoy SWAT Portal forum in different colors / themes

Just install the Stylus browser extension and use one of these themes to change the SWAT Portal forum colors.

All theme files are hosted here:

https://flathack.github.io/docs/swat-portal-themes.html

How to use

  1. Install Stylus for your browser.
  2. Open one of the UserStyle links below.
  3. Confirm the style in Stylus.
  4. Reload SWAT Portal.

Target page pattern: https://swat-portal.com/*

Available themes

  • Open Aurora CSS
